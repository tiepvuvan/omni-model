---
title: Quickstart
description: Get a working omni-model proxy and make your first request.
---

omni-model runs as a container backed by PostgreSQL, and exposes a standard HTTP endpoint any
OpenAI SDK can hit.

<Steps>
  <Step title="Start PostgreSQL">
    Any Postgres 14+ instance works. For a local run:

    ```sh
    docker run -d --name omni-db -p 5432:5432 \
      -e POSTGRES_USER=omni -e POSTGRES_PASSWORD=secret -e POSTGRES_DB=omni \
      postgres:17-alpine
    ```
  </Step>
  <Step title="Set configuration variables">
    Configuration is read from the deployment environment:

    ```sh
    DATABASE_URL=postgres://omni:secret@localhost:5432/omni
    OMNI_STORAGE_TYPE=postgres
    OMNI_STORAGE_POSTGRES_URL='${DATABASE_URL}'
    OMNI_JWT_SECRET=replace-with-a-long-random-secret
    OMNI_SECURITY_JWT_ENABLED=true
    OMNI_SECURITY_JWT_SECRET='${OMNI_JWT_SECRET}'
    OMNI_SECURITY_JWT_ALGORITHMS='["HS256"]'
    OMNI_TARGET_TYPE=openai
    OMNI_TARGET_API_KEY='${OPENAI_API_KEY}'
    OMNI_RATE_LIMITS_JSON='[{"name":"per-user-requests","key":"user","requests":{"limit":30,"window":"1h"}},{"name":"per-user-daily-tokens","key":"user","tokens":{"limit":30000,"window":"1d"}}]'
    OMNI_TARGET_TYPE=default
    ```

    <Note>
      At least one [security verifier](/security/custom-jwt) is required — the proxy refuses to
      start without one, because a proxy that authenticates nobody is an open relay on your
      provider credits. For a public app, prefer
      [App Attest or App Check](/security/verify-on-device) over a shared secret.
    </Note>
  </Step>
  <Step title="Run it">
    Use the prebuilt image (no clone, no build):

    ```sh
    docker run -p 8787:8787 \
      -e OPENAI_API_KEY=sk-... \
      -e DATABASE_URL=postgres://omni:secret@host.docker.internal:5432/omni \
      -e OMNI_JWT_SECRET=replace-with-a-long-random-secret \
      -e OMNI_STORAGE_TYPE=postgres \
      -e 'OMNI_STORAGE_POSTGRES_URL=${DATABASE_URL}' \
      -e OMNI_SECURITY_JWT_ENABLED=true \
      -e 'OMNI_SECURITY_JWT_SECRET=${OMNI_JWT_SECRET}' \
      -e 'OMNI_SECURITY_JWT_ALGORITHMS=["HS256"]' \
      -e OMNI_TARGET_TYPE=openai \
      -e 'OMNI_TARGET_API_KEY=${OPENAI_API_KEY}' \
      ghcr.io/tiepvuvan/omni-model:latest
    ```

    See [Installation → Docker](/installation/docker) for Compose, health checks, and scaling out.
  </Step>
  <Step title="Make a request">
    Generate a publishable key in the dashboard, sign an HS256 JWT with `OMNI_JWT_SECRET`, and send
    both credentials:

    ```sh
    curl http://localhost:8787/v1/chat/completions \
      -H "authorization: Bearer $PUBLISHABLE_KEY" \
      -H "x-omni-user-token: $YOUR_JWT" \
      -H "content-type: application/json" \
      -d '{"model": "gpt-4o-mini", "messages": [{"role": "user", "content": "Hello!"}]}'
    ```
  </Step>
</Steps>
