title: omni-model
description: Ship AI features from client apps without exposing provider keys.
---

omni-model is an **OpenAI-compatible LLM proxy you run yourself**. Provider keys stay on your
infrastructure instead of inside a web bundle or app binary. Configure the security and policy layer
from a dashboard, then call it with the OpenAI-compatible SDK your app already uses.

## How it works

```text
Client (any OpenAI SDK)
        │  { "model": "smart", "messages": [...] }
        ▼
┌─────────────────────────────────────────────┐
│  omni-model — your infrastructure           │
│   1. authenticate   Firebase / Supabase /     │
│                     Clerk / Cognito / JWT    │
│   2. attest         App Check / App Attest /  │
│                     Play Integrity / more    │
│   3. protect        input + token budgets     │
│   4. route          CEL policy                │
└───────────────┬─────────────────────────────┘
                │  translated on the fly
      ┌─────────┼──────────┬───────────────┬───────────────────────┐
      ▼         ▼          ▼               ▼                       ▼
   OpenAI   DeepSeek   Anthropic   Google Gemini   any OpenAI-compatible endpoint
```

Requests to Anthropic and Gemini are translated to and from the OpenAI wire format automatically —
streaming included — so your client keeps speaking one protocol everywhere.
